# Локальный сайт V&A

Запустите START-LOCAL.cmd и откройте http://127.0.0.1:5178/.
Для запуска нужен Python. Окно сервера оставьте открытым; Ctrl+C останавливает его.

Исходники: index.html, src и assets. Готовая публикационная сборка: dist.
Команды разработчика: npm run check, npm run build.

Интернет нужен для обложек и превью Apple Music, VK Видео и Spotify.
Локальные изображения, шрифты, северный фон и интерфейс лежат в этой папке.

Проверка браузером: установите Playwright вне публикационной сборки и запустите tools/browser-check.cjs.
PLAYWRIGHT_MODULE может указывать путь к установленному пакету, SITE_URL — адрес проверяемого сервера.

Публичный сайт: https://ver-dikt.github.io/VA-SITE/
Статистика в интерфейсе — сохранённый срез, пояснения доступны под карточками.
